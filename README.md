# 老婆的小本本

記錄老婆說過的事：想去的地方、想吃的美食、禮物靈感、喜好與地雷、習慣小事、重要資訊（含每年倒數的紀念日）。

- 心願清單：想去／想吃／禮物可以打勾完成，有進度圈和完成日期
- 一鍵 Google 地圖：用地點名稱搜尋，或貼上 Google 地圖分享連結
- 照片：每一筆都能上傳照片（自動壓縮），在「回憶牆」集中瀏覽
- 快捷功能：「今天去哪玩？」「今天吃什麼？」隨機抽、送禮靈感頁、搜尋與 #標籤
- 雲端儲存：以 claude.ai Artifact 發布，資料存在 Artifact 資料庫（`items` 集合），照片存在 Artifact 素材庫

`index.html` 是發布到 claude.ai 的頁面原始碼。在 claude.ai 之外直接開啟時，會改用瀏覽器本機暫存（不會同步）。
